⚙️ Setup Required

Before you can use this calendar viewer, you need to create a Google Cloud project and get API credentials:

  1. Go to Google Cloud Console
  2. Create a new project or select an existing one
  3. Enable the Google Calendar API
  4. Go to "Credentials" → "Create Credentials" → "API Key"
  5. Copy the API Key and paste it below
  6. Go to "Credentials" → "Create Credentials" → "OAuth 2.0 Client ID"
  7. For Application type, choose "Web application"
  8. Add your GitHub Pages URL to "Authorized JavaScript origins"
